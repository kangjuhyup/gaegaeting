# 디자인 에셋

사진과 SVG 아이콘은 [개개팅 Figma](https://www.figma.com/design/pcCLqdVZ1YqFb4mQoMNkHj/?node-id=0-1)의 원본 에셋입니다. 사진은 로컬로 내려받은 같은 Figma 파일의 image fill을 사용하며, SVG는 Components 페이지에서 직접 내보냈습니다. 화면 캡처를 UI 이미지로 사용하지 않습니다.

Figma 컴포넌트 설명에 기록된 사진 출처: [golden retriever](https://unsplash.com/photos/golden-retriever-x5oPmHmY3kQ), [adult golden retriever](https://unsplash.com/photos/adult-golden-retriever-WpLC86UD7Lk). 샘플 사진이며 실제 회원 사진이 아닙니다.

Noto Sans KR은 [Google Fonts 원본](https://github.com/google/fonts/tree/main/ofl/notosanskr)을 앱에 포함했습니다. 라이선스는 `fonts/OFL.txt`에 보관합니다. 카카오 심볼과 색상은 Figma에 지정된 [카카오 로그인 디자인 가이드](https://developers.kakao.com/docs/ko/kakaologin/design-guide)를 따릅니다.
